# Main-figure source data

This directory contains the numerical source tables underlying or directly
supporting manuscript Figures 1–6.

The files were copied from frozen, canonical or final analysis outputs.
No statistical tests, effect sizes, P values, module scores or enrichment
statistics were recomputed during preparation of this repository package.

## Figure mapping

- Figure 1: developmental trajectory programmes and functional enrichment
- Figure 2: discovery developmental regulatory atlas
- Figure 3: perturbational transcriptomic evidence hierarchy
- Figure 4: developmental hierarchy and adult cortical phenotype correspondence
- Figure 5: prospective/representative fetal spatial localization
- Figure 6: whole-transcriptome fetal spatial organization

`FIGURE_SOURCE_DATA_MANIFEST.tsv` records the original project-relative
location, public repository location, file size and SHA256 checksum for every
source-data file.

Some source tables intentionally overlap with Supplementary Tables because
the same locked numerical results support both a manuscript figure and a
supplementary data table.
